# 2026 Bundibugyo Ebola importation risk and readiness
Repository containing the data underlying the analyses presented in the publication _Importation risk and preparedness priorities across Africa in the 2026 Bundibugyo Ebola outbreak: a modelling study_.

`/code` contains the code used for the analyses. Detailed instructions and requirements are provided in the README within this folder.

`/demo` contains the same analysis code together with **synthetic** input data, allowing to test the full workflow. 

The repository root  contains the data underlying the main results presented in the paper.
